# Cogitone AI Bot 🌿

একটি টেলিগ্রাম বট যা **Google Gemini AI** ব্যবহার করে প্রশ্নের উত্তর দেয় এবং পড়াশোনায় সাহায্য করে। HSC বোটানি ও অন্যান্য বিষয়ের জন্য তৈরি।

## 📌 ফিচারসমূহ
- যেকোনো প্রশ্নের উত্তর দেয় (AI দিয়ে)
- PDF থেকে কুইজ তৈরি করতে পারে
- ২৪/৭ অনলাইন (Koyeb হোস্টিং)

## 🚀 কীভাবে ব্যবহার করবেন
1. টেলিগ্রাম খুলে বটে যান: [@cogitone_Ai_Bot](https://t.me/cogitone_Ai_Bot)
2. `/start` লিখুন
3. যেকোনো প্রশ্ন করুন অথবা PDF পাঠান

## 🛠 টেকনোলজি
- Python 3
- python-telegram-bot
- Google Gemini AI API
- Koyeb / Termux
